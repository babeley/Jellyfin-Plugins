Catalogue

Ajoute un bouton flottant qui ouvre votre catalogue externe dans le client web Jellyfin. Nécessite le plugin File Transformation (installé et Jellyfin redémarré).

URL complète du catalogue, token d'accès inclus. Modifiable à tout moment sans reconstruire le plugin.
Si décoché, le catalogue remplace l'onglet Jellyfin en cours.
